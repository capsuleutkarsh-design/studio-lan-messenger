# Quillo 1.11.1

A smaller server: the EXR / DPX / TIFF / MOV previews from 1.11.0 are taken out again.

## What changed
- **No more EXR / MOV previews.** EXR frames, DPX, TIFF and video clips show as file cards again (name, size,
  Download / Open), like before 1.11.0. Normal pictures (PNG, JPG...) still show a preview, a gallery and the
  full-window viewer.
- **FFmpeg is no longer part of Quillo.** The server installer is back to about 52 MB (it was 75 MB), and there is
  no `ffmpeg.exe` or `FFMPEG-LICENSE.txt` next to the server any more - so nothing to add to the third-party
  notices either.

Everything else from 1.11.0 stays: shot status, drawing on a picture, comparing two versions, next-unread,
mark all as read, saved for later, drafts, "In a meeting", the leave auto-reply, the update tracker and
"Not seen in 30 days" - see [what's new in 1.11.0](v1.11.0.md).

## ⬆️ Upgrading
Install over 1.11.0 or 1.10.0: **the server first, then every PC** (console → Updates → Publish client update,
then *Install now* - or **Remind them**). Nothing is lost. If a 1.11.0 server made previews, their small files
in the storage folder's `.thumbs` folder can be deleted.
