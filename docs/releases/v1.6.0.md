# Quillo 1.6.0

**LAN Messenger is now Quillo.** A new name, a new logo, a licence, 131 new stickers and a softer look for the
chat app. Everything else works exactly as before, and upgrading keeps all your chats, files and settings.

## ✨ What's new

### A new name and logo
- The app is now called **Quillo**; the server is **Quillo Server**. Window titles, the tray, the installers,
  Start menu and desktop shortcuts all use the new name.
- New logo: a **Q with a quill feather** on a soft white tile. It reads clearly from the taskbar (16 px) up to the
  sign-in screen, on light and dark themes alike.

### Licence
- Quillo is released under the **Quillo Community License** by Utkarsh Tripathi (see [LICENSE](../../LICENSE)):
  - **Free** to download, install and use, including across a whole studio.
  - **Changed it?** Tell the author (open an issue on GitHub) and share your source code back to the repository.
- The installers show the licence before installing, and a **"Quillo licence"** shortcut is added to the
  Start menu.
- A very small *Quillo Community License · © 2026 Utkarsh Tripathi* line sits at the bottom of the sign-in
  screen, the main window and the server console. Click it to read the licence.

### A softer chat app
The same minimal, soft style as the server console, now in the client:
- No hard divider lines between the menu rail, the chat list and the chat.
- Home cards, quick actions and panels are borderless, with rounder corners.
- Rounder message bubbles and a rounder message box, with softer edges on inputs, buttons, menus, polls and
  popups.
- Works in every theme: Midnight, Light, Classic and the festival looks.

## 🔧 Also fixed
- Server installer: the after-install page now describes the default **"just for me"** install correctly (where
  the program goes, and that Windows Firewall asks once).
- The server installer now also spots a server running in another user's session before replacing files.
- README: corrected the sticker count and the old "automatic department rooms" wording.

## ⬆️ Upgrading from LAN Messenger
- Just run the new installers over the old version. **Nothing is lost.** Data folders, registry settings, the
  background service, firewall rules and program files keep their old internal names on purpose, so the upgrade
  finds everything.
- Old "LAN Messenger" Start menu and desktop shortcuts are replaced by "Quillo" ones.
- **Client updates from the console:** the server accepts both the new `Quillo-Client-Setup-x.y.z.exe` and old
  `LANMessenger-Client-Setup-x.y.z.exe` names in its updates folder.
- Existing users keep their download folder (`Downloads\LAN Messenger`); new installs use `Downloads\Quillo`.
