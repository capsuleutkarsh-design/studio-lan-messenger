# Quillo 1.6.1

Every issue from the code audit is fixed, plus five additions: shot & path links, typed scheduling times, a Storage
page, file retention per room, and the Quillo navy & teal look.

## ✨ New

### 📁 Shot and path links
Paste a studio path and it becomes a link, shown with a 📁:
- `\\fs01\proj\FAL\FAL_030\comp\v012` (network share)
- `Z:\proj\...` or Nuke-style `Z:/proj/...` and `//fs01/proj/...`
- **Frame sequences** like `FAL_030.####.exr` or `plate.%04d.dpx` open the folder that holds the frames
- Paths with spaces work in quotes: `"\\fs01\My Project\shot 01"`

Clicking one shows a small menu: **Open folder / Show in Explorer**, **Open file** and **Copy path**. Programs and
scripts (`.exe`, `.bat`, `.ps1`, ...) are never started from a link. If the path can't be reached from your PC, you
are told so (network paths are checked in the background, so the chat never freezes).

### ⏰ Schedule a message or reminder by typing when
In the *Send later* and *Reminder* windows, type the time the way you would say it:
`mon 9:30` · `tomorrow 2pm` · `in 2h` · `in 3 days` · `fri` · `28 sep 10:00` · `5/10 16:15` · `tonight`.
The window shows what it understood (✓ *Mon 28 Sep 09:30*) before you confirm. The *Send later* menu also gets
**Another day, 09:00** with the next working days.

### 💾 Storage page (server console)
Console → **Storage** shows:
- the space used, the number of files, the free space on the disk and the oldest file
- the space **by person**, **by chat** and the **largest files**, with who sent them, where, and how often they
  were downloaded
- **Clean up now**: delete every shared file older than *N* days, straight away (recorded in the audit log)

### 🗂️ Keep files per room
Console → **Rooms** → **Keep files...**: a room can keep its shared files *Forever*, for a number of days, or follow
the server default. For example, keep plates forever while dailies go after 30 days. A file posted in several chats
stays as long as the longest of them keeps it.

### 🎨 Quillo navy & teal
A new **Quillo** accent matching the logo: in the dark theme the surfaces turn deep navy with teal highlights; in
the light theme the rail gets a navy tint. It is the default for **new** users and for the server console. Existing
users keep the colour they chose, and anyone can switch in Settings → Accent colour (the half-navy, half-teal
swatch).

## 🔧 Fixed (from the audit)

**Server**
- The nightly database backup no longer pauses chat: it now copies in the background. Before, a large database
  could stall everyone and even disconnect people.
- An administrator who is disabled, deleted or loses admin rights loses an open **server console** straight away.
- Failed sign-in records are cleaned up, so the list can't grow for ever.
- Muting a chat checks the other person exists (a faulty client could fill the database).
- People who must change their password can't upload, download or share their screen until they have done so.
- Unexpected server errors no longer show internal details to the user (they are in the server log).
- A damaged `settings_version` or a negative size or day setting in `config.json` no longer resets all settings.
- Saving a room that was deleted in the meantime says so instead of failing with "Invalid request".
- Starting the server again while it is still stopping no longer starts it twice.

**Client**
- Names of rooms and people are always shown as typed. A room called `<b>...</b>` can no longer inject
  formatting into dialogs and tooltips.
- When you are signed out by the server, or a reconnect is refused, the previous account's pop-ups, reminders,
  open chat and transfers are closed.
- Reconnecting while another page is open: the chat reloads when you go back to it, so messages from while you were
  offline show and scrolling up loads history again.
- *Retry* on an upload whose file (or packed folder) is gone tells you so instead of showing an error.
- *Save as...* over a name that has an old, half-finished download no longer mixes the two files.
- One unexpected message from the server can no longer drop the other messages that arrived with it.
- Open "Searching..." and similar windows get an answer when the connection drops or you sign out.
- Compact window: Nuke-script cards and polls fit the narrow window; notices stay on screen.
- The silent autostart copy no longer pops the window open when Windows starts a second time.
- A person with an empty display name no longer causes an error in the chat list or typing indicator.

**Installer**
- A storage, backup or log folder with non-English characters (e.g. `D:\Pröjekt`) is shown and kept correctly on
  upgrade. `config.json` is now saved as UTF-8. When upgrading from 1.6.0 or older, a folder like that is also
  kept correctly.

## ⬆️ Upgrading
Install over 1.6.0 (or any LAN Messenger version); nothing is lost. The database gets one new column (per-room file
retention) automatically.
