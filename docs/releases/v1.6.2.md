# Quillo 1.6.2

Rooms that keep working when their creator leaves, a full list of VFX designations, changing your own name,
notifications that really open the chat, one-click updates, send-later to the second, and sharper screen sharing.

## ✨ New

### 👑 Room owners
- When the **owner leaves**, the member who has been in the room the longest becomes the owner automatically
  ("Priya is now the room owner"). Before, nobody but an administrator could rename the room or remove people any
  more.
- The owner can hand the room over: *Room info → select a member → **Make owner***.
- When the **last person leaves**, the room is closed instead of staying around empty.

### 🎬 VFX designations
Every server now has the designations a VFX studio uses, with sensible permissions:
- **Leadership:** Studio Head, Executive Producer, VFX Supervisor, VFX Producer, Associate VFX Supervisor,
  DFX Supervisor
- **Supervisors:** CG, Compositing, FX, Lighting, Animation, Pipeline, Roto/Paint, Matchmove, DMP, Assets
- **Production:** Line Producer, Production Manager, Production Coordinator, Production Assistant
- **Leads:** Compositing, FX, Lighting, Animation, Roto, Paint, Matchmove, Modeling, Texturing, Rigging, Layout, DMP
- **Artists and TDs:** Senior Compositor, Compositor, FX Artist, FX TD, Lighting Artist, Lighting TD, Look Dev,
  Animator, CFX, Layout, Modeler, Texture Artist, Rigger, Environment Artist, Matte Painter, Concept Artist,
  Matchmove, Roto, Paint and Prep artists
- **Pipeline and IT:** Pipeline TD, Render Wrangler, Data I/O, Editor, System Administrator, Intern

The designations you already had are unchanged. The list is added once, so any you delete stay deleted.

### ✏️ Change your own name
*Profile → ✏ next to your name.* Everyone sees the new name straight away. Administrators can switch this off
(*Settings → People can change their own display name*); every change is in the audit log.

### 🔔 Notifications open properly
Clicking a notification now brings Quillo to the front and opens that chat, including from the tray, when
minimised, and in compact mode. Before, Windows often only flashed the taskbar button. Reminder notifications now
open their chat too.

### ⬆️ Updates
- Console → **Updates** (renamed from *Client updates*):
  - **Publish client update...** picks the new `Quillo-Client-Setup-x.y.z.exe`; every signed-in PC is told
    straight away.
  - **Update this server...** runs a new server setup from the console.
  - A table of the versions the signed-in PCs run, so you can see who is behind. *Online now* shows each
    person's version.
- PCs where Quillo was installed **"just for me"** now update with one click and **no administrator password**.
- *Settings → **Check for updates*** in the app.

### ⏱️ Send later, to the second
- New quick picks: **In 1 minute** and **In 5 minutes**.
- **In [ 30 ] [ seconds / minutes / hours / days ]**: any delay, down to 1 second.
- Type it: `in 30s`, `in 90 seconds`, `14:05:30`, `mon 9:30`, `tomorrow 2pm`.
- The time field shows seconds, and the server checks every second (it was every 5).

### 🖥️ Sharper screen sharing, still easy on the network
- Up to **8 fps** while things move (it was 4), and up to **2560 px** wide, so 4K screens stay readable.
- When the picture stops moving, one **sharp** frame follows, so code and small text become crisp. Typing and a
  blinking cursor stay sharp too (at most one sharp update a second).
- Quality follows the network: when frames queue up, quality drops and frames are skipped, so chat, file
  transfers and ping are not squeezed. A still screen is checked less often, which saves CPU.
- The viewer shows the frame rate.

## 🔧 Also
- Designations, names and room owners are covered by new tests. 97 automated tests in total, all passing.

## ⬆️ Upgrading
Install over 1.6.1 (server first, then clients, for example with *Publish client update*). Nothing is lost.
