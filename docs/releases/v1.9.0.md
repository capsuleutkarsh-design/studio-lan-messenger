# Quillo 1.9.0

Steadier with a whole studio online, nothing lost when the server or the network blinks, threads, better
search - and administrators can no longer read people's chats.

## 🧵 Threads
Reply to a message in a **thread**, so a long back-and-forth doesn't bury the rest of the chat.
- Right-click a message → **Reply in a thread**. The thread opens in a panel on the right.
- The chat shows **💬 2 replies · last today 15:20** under the first message; click it to open the thread.
- Tick **Also send to the chat** when everyone should see a reply.
- You're told about new replies in threads you started or replied in (or where you're @mentioned). Replies
  that live only in a thread don't make the chat unread.

## 📮 Messages wait for the server
When the server is being restarted, the server PC is off or the network drops, **what you type is no longer
lost**. Messages wait in the chat, greyed with a 🕓, and go out in order as soon as Quillo is connected again,
even after Quillo or the PC was restarted. Click ✕ on one to take it back.
- A message is never stored twice, even if the connection drops just as it was sent.
- If the server refuses a message, its text goes back into **that chat's** box, not the chat you have open now.

## 📁 Big files: no more starting from zero
- An upload the network interrupts **carries on from where it stopped**, by itself (up to 5 times). *Retry*
  carries on too. Before, a 10 GB upload started again from the beginning.
- A finished upload is never lost if the chat connection was reconnecting at that moment: it's posted as soon
  as the connection is back.
- Uploads no longer slow down the chat for everyone while they're written to a shared folder.

## 🔍 Better search
Search now has filters: **from a person**, **in a chat**, **between two dates** and **files only**. You can
search with a filter alone (e.g. everything Ben sent), and **Show older results** goes past the first 200.
A result in a thread opens the thread.

## 🗂️ The central folder: everything important on your file server
For studios whose server PC may break, be replaced or go back (rented PCs): the **central folder**
(`Quillo server data`, inside the shared files folder on your file server) now holds everything a new server
PC needs:

| | |
|---|---|
| a copy of the database, settings, certificate, photos | every 5 minutes, and when the server stops |
| **Chat backup\Rooms\\**`<room>`**\2026-09.txt** | every room, one text file per month |
| **Chat backup\People\\**`<A + B>`**\2026-09.txt** | every direct chat, one text file per month |
| **User list\Users.xlsx** and **Users.csv** | everyone; the Excel file can be imported into any Quillo server |
| **Database backups** | the nightly backups |

Install the server on a new PC, choose the same shared files folder, and setup offers to restore everything.
The server's installer and *Settings → Central folder* explain it.
Your old month-by-month chat logs are kept as **Chat backup\Before 1.9.0**.

## 🔒 Privacy and safety
- **Administrators can no longer read people's chats.** The *Chat review* page, its setting and the "chats may
  be reviewed" notice are gone.
- **Chats are kept for good.** Old servers removed messages older than 90 days from the app; every server now
  keeps them (they are in the chat backup as well).
- **Links to other computers ask first.** A `\\computer\share` link to a machine that isn't one of your studio's
  file servers asks before Quillo even looks at it, because opening it lets that computer see your Windows
  sign-in. List your file servers in the server console: *Settings → Studio file servers*. There's also
  "Don't ask again for this computer".
- **Programs are never started from a chat.** Programs, scripts, shortcuts and disk images (`.exe`, `.bat`,
  `.hta`, `.lnk`, `.iso` and many more) are shown in their folder instead of being run.

## ⚡ Steadier with the whole studio online
- **Signing in is fast on a big server.** Every sign-in used to read through every message ever sent; after a
  server restart, 50 PCs signing in together could freeze the chats for minutes. The first start of 1.9.0
  builds two indexes once (a few seconds on a big server).
- **"Back up now", "Copy now" and "Import users" no longer freeze everyone's chat**; they run in the
  background. So do the nightly jobs, and one slow job (a copy to a slow share) no longer holds up the others.
- **The 5-minute safe copy can't get stuck.** On a busy server it could keep starting over and never finish.
- **Importing 100 people** sends everyone's updated list once at the end, not 100 times.
- **"My space" no longer shows an unread count** for your own notes after signing in.
- **Changing to light / dark mode restarts Quillo properly.** When Quillo had started with Windows, it came
  back hidden in the tray and looked as if it had not restarted.
- **Home: the calendar card has month arrows** (‹ October 2026 ›), the mouse wheel moves between months, and
  *Today* comes back.

## ⬆️ Upgrading
Install over 1.8.0: **the server first, then every PC.** Nothing is lost.
- The first start of the new server takes a little longer on a big database (new indexes), and writes the whole
  chat history once into the new chat backup layout.
- A PC still on 1.8.0 shows thread replies as normal messages until it's updated.
- If your shared files are on the server PC itself, there is no central folder yet: the dashboard says so.
  Point *Settings → Central folder* (or the shared files folder) at your file server.
