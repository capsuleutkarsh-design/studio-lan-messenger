# Quillo 1.12.0

Room pictures, 120 new stickers, a calendar that scrolls, and a careful polish of every screen.

## 🖼 Room pictures
- **Give a room its own picture.** Open the room's members (👥 in the chat header) → **Change picture...**. It
  shows in everyone's chat list, on Home, in the chat header and in *Forward*. **Remove** takes it off again.
- The **room owner** or an **admin** can change it. Automatic department / section rooms have no owner, so there
  only an admin can.
- The room gets a small line when it changes: *"Priya changed the room picture"*.

## 😄 120 new stickers - 6 new packs
Quillo now has **579 stickers in 17 packs**, all drawn for Quillo:
- **Chai Sutta** - tea and smoke breaks ("Chai sutta break?", "Bas 5 minute!").
- **Lunch Chat** - a whole lunch conversation in stickers alone: *Khana aa gaya!*, *Aaj paneer hai!*, *Veg hai*,
  *Non-veg hai*, *Aaj khana ghatiya hai*, *Mera share rakhna*, *Pet bhar gaya*...
- **Food** - poha jalebi, pav bhaji, misal pav and friends.
- **Late Night** - "Raat ke 2 baj gaye", "Render laga ke so ja", "Ullu mode ON".
- **Day & Night** - for the weeks you don't go home: "3 din se yahin hoon", "Zombie mode ON", "Delivery ho gayi!".
- **Bollywood Memes** - the famous lines, said by Quillo's own cast.

## 📅 Calendar
- **The month view scrolls.** Busy weeks grow taller, so a day lists up to six meetings, leave days and
  birthdays before it says "+N more". The day names stay at the top while you scroll.

## ✨ Polish across every screen
A full review of every window found 182 small and big rough spots, all fixed. The look and layout stay the same.
- **Small windows work.** At the smallest window size, with a thread open, nothing is cut off any more. The
  thread panel shrinks first, and the compact (docked) view fits pictures and file cards.
- **Long text ends in "…"** instead of being cut mid-letter: chat names, subtitles, pinned messages, reply
  quotes, path cards. Long file names keep their extension (`AK74_0450_comp_v012_final….exr`).
- **Menus open inside the window** (the clock, ⋯ and pinned menus used to hang off the right edge), and right-click
  menus are grouped.
- **One date format everywhere**, one set of icons, readable grey text and names in the light theme, and person
  colours that are easier to tell apart.
- **Clearer wording** on buttons and messages, and a question before anything risky.
- Many small fixes: the Send button no longer looks ready in an empty chat, @mention suggestions no longer
  cover the reply bar, "Pick a date & time..." shows its "&", "Seen by" counts update live, and more.

## ⬆️ Upgrading
Install over 1.11.1 (or 1.11.0 / 1.10.0): **the server first, then every PC** (console → Updates → Publish
client update, then *Install now* - or **Remind them**). Nothing is lost. Room pictures need the 1.12.0 server;
older Quillo clients simply show the room's letters.
