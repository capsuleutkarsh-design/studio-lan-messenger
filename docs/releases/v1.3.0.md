# LAN Messenger 1.3.0

Studio chat, file sharing and screen sharing that runs **entirely on your own network**: nothing goes to the
internet. Install the server once, the client on every PC.

## Highlights

### A new look
- New **Prism** app icon, and a redesigned interface: navigation rail with labels, cleaner chat list with
  **All / Unread / People / Rooms** filters, grouped chat bubbles, a pinned-message card, and a new composer
- Three themes (**Midnight**, **Light**, **Classic** black & lime) with six accent colours, under Settings
- Two-panel sign-in screen and a new home page with tips
- Shortcuts: **Ctrl+K** find a person or room · **Ctrl+F** search messages · **↑** edit your last message

### More fun, more useful
- **Stickers**: 185 stickers in 15 packs (desi chat, Uncle Ji, Haryanvi, moods, Holi, Diwali, festivals,
  Independence & Republic Day and more), with a recently-used tab
- **Emoji reactions** on any message: hover a message and click 🙂
- **Polls**: single or multiple answers, optional anonymous voting, live results; the creator can close them
- **Profile photos** and a **custom status** with emoji and "clear after"
  (e.g. 🍽️ Out for lunch · 1 hour, 🎬 Rendering, don't touch my PC)
- **Organisation page** with three views: people **cards** in rows and columns, an **org chart** of who
  reports to whom (zoom, fit, search highlights), or the classic **list**. Filter by department.
  The server console's Org chart page uses the same views.

### Nuke scripts and long text
- A message can now hold **100,000 characters** (about 2,500 lines of Nuke script).
  Earlier versions silently cut messages at 20,000 characters; that is fixed.
- Long text and anything that looks like a Nuke script appears as a compact **code card**:
  preview, *Show all*, *Copy* (paste straight into Nuke with Ctrl+V) and *Save as .nk*. The chat never
  freezes on it.
- Text longer than the limit is offered as a `.nk` / `.txt` file automatically.

### Fixes
- The first sign-in after starting the app now always shows the forced password change, the chat-review
  notice and unread announcements (they could be skipped before).
- Faster handling of very large messages and history pages.

## Everything else that's included
Direct chats and rooms (with automatic department / section rooms) · read receipts and typing indicator ·
reply, edit, delete, forward, pin, mute, @mentions, "seen by" · files up to **20 GB** each (resumable),
drag & drop, paste screenshots, whole folders (zipped, one-click extract), image previews · announcements
with read tracking · view-only **screen sharing** with consent · encrypted connections (TLS) with
server-identity checks · designations with permissions, reporting lines · server as a Windows service,

## Install

1. **Server:** run `LANMessenger-Server-Setup-1.3.0.exe` as administrator on an always-on PC. Keep the
   tasks *Allow through Windows Firewall* and *Run as a background service*.
2. Open **LAN Messenger Server** from the Start menu and sign in as **admin / admin**; you must choose a new
   password straight away. Add people under **Users** (or *Import CSV*) and set up **Designations**.
3. **Clients:** run `LANMessenger-Client-Setup-1.3.0.exe` on every PC. Leave the server address empty and
   the client finds the server by itself (enter its IP only if the PC is on another subnet).
   Silent install for IT:
   `LANMessenger-Client-Setup-1.3.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SERVER=192.168.1.10`

## Upgrading from 1.2 or earlier
- **Upgrade the server first**, then the clients. Run the new setup over the old one; accounts, messages,
  files and settings are kept and the database updates itself on start.
- Tip: in the console use **Settings → Back up now** before upgrading.
- To update every PC from the server, copy `LANMessenger-Client-Setup-1.3.0.exe` into the server's
  `updates` folder (console → *Client updates*); clients offer to install it.
- Older clients keep working with the new server, but they show stickers and polls as plain text. Update
  them soon.

## Requirements
- Windows 10 or 11, 64-bit, on every PC
- Network ports on the server: **TCP 5150** (chat, files, screen sharing), **UDP 5151** (discovery),
  **TCP 5152** only if the pipeline API is switched on. The server setup allows the server program through
  Windows Firewall, which covers all three.

## Known limits
- One server per studio; tested with 1,000 people online at the same time.
- Screen sharing is view-only (no remote control).
