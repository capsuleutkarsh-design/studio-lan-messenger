# Quillo 1.7.1

A much faster server console, your data safe in the central folder, and a better Excel people list.

## 🐢➡️⚡ The console no longer lags
Pages with tables re-measured every column after **every single cell** they filled, and refreshed every 5
seconds. With a studio's worth of people, the window was busy almost all the time, and the processor with it.

| Page (150 people) | Before | Now |
|---|---|---|
| Users | 4.7 s per refresh | 0.01 s |
| Audit log | 4.1 s | 0.01 s |
| Designations | 2.3 s | 0.01 s |

- Tables fill in one go. **The selected row and the scroll position stay put** when a page refreshes.
- Only *Dashboard* and *Online now* refresh every few seconds. The other pages refresh when you open them, when
  something changes, and once a minute.
- If the server is ever stuck for more than a second, the **Server log** says what it was doing, so a slowdown
  names its own cause.

## 💾 A safe copy for reinstalls
When the shared files are on a network share (or another disk), the server keeps a copy of **everything it needs
to come back** in `<shared files>\Quillo server data`:
- every account and chat, rooms, the calendar and holidays
- the settings
- the server certificate, so the PCs keep trusting the server
- profile photos

It is updated **every 5 minutes** when something changed, and when the server stops. The Dashboard shows the
last copy; *Settings → Safe copy* has the folder, the interval and *Copy now*.

**On a new install**, pick the same shared-files folder: setup finds the copy and asks
*"Restore it? (Server: Studio, People: 80 ...)"*. Everything comes back.

Also: uninstall no longer forgets where the data folder is, so a reinstall finds the existing data by itself.

> The live database stays on the server PC's own disk: a database run directly from a network share is slow and
> can be damaged when the connection drops mid-write. The copy on the share is complete and consistent.
> It holds every chat and the password hashes, so give only administrators and the server access to that share.

## 📊 Excel people list
- **The dropdowns work everywhere.** They listed nothing in some versions of Excel (and in WPS and Google
  Sheets). They show every department, section, designation (including ones you just created) and person.
- **Visible cell lines** in a soft blue-grey, and a darker line under the headers.
- Clicking a dropdown cell shows a "Pick from the list" hint.

## ⬆️ Upgrading
Install over 1.7.0: the server first, then the clients. Nothing is lost. The first safe copy is made within 5
minutes of starting.
